# Mzansi AI Educator — Video Link Repository

Status: POPULATED LINK-ONLY RESOURCE
Last reviewed: 2026-08-19

Purpose: Optional external learning videos mapped to the existing curriculum. Videos supplement the built-in lessons and never replace them. Core lessons, quizzes, progress and certificates remain usable without video access.

## Learner note

Video links require an internet connection and may use mobile data. Use Wi-Fi where available. The lesson itself remains available offline.

## Governance

- External links only. No video embedding in the PWA.
- Prefer established education and public-interest providers.
- Do not require a video for lesson completion.
- Recheck links periodically and retire broken or unsuitable resources.
