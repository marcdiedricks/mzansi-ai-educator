# Mzansi AI Educator — Video Link Repository

Status: CONTROLLED LINK-ONLY RESOURCE

Purpose: Keep optional external learning videos mapped to the existing curriculum without embedding or bundling video media in the PWA. Core lessons must remain usable offline without these links.

## Governance rules

- External links only. No embedded video files.
- A video supplements a lesson. It never replaces the built-in lesson.
- Prefer credible educational, university, public-interest, standards, or established technology-education sources.
- Check learner suitability, relevance, language, accessibility and link health before marking APPROVED.
- Do not require video access for lesson completion, quizzes, progress or certificates.
- Keep the PWA's core learning path functional when offline or when mobile data is unaffordable.
- Mark unverified resources CANDIDATE. Only reviewed links become APPROVED.

## Resource fields

Each resource must record:

- Lesson ID
- Lesson title
- Video title
- Provider/channel
- Language
- Approximate duration
- URL
- Last checked
- Status: CANDIDATE | APPROVED | RETIRED
- Review note

## Maintenance

Review APPROVED links periodically. If a link breaks, becomes unsuitable, changes substantially, or moves behind a paywall/login that undermines learner access, mark it RETIRED and replace it with a reviewed alternative. Never remove the offline built-in lesson because an external video exists.
